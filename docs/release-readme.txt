GeGeGe no Kitarou: Fukkatsu! Tenma Daiou - English translation {version}
================================================================

Unofficial English fan translation of "GeGeGe no Kitarou: Fukkatsu! Tenma Daiou" (Super Famicom, Bandai, 1993).
This zip holds only a patch. No ROM is included and none will be shared.

What is translated
------------------
Everything: cutscene captions, the intro letter, in-stage dialogue, chapter cards, boss names, the HUD icon,
title (logo romanised), menus, options, partner select, game over, staff roll and the signs in the city picture.
The invented alien script on two boss names and two captions is kept as drawn, as in the original.

How to patch
------------
1. You need this exact dump (No-Intro):
     Gegege no Kitarou - Fukkatsu! Tenma Daiou (Japan).sfc
     Size   {size} bytes (headerless)
     CRC32  {crc}
     MD5    {md5}
     SHA-1  {sha1}
2. Apply {patch} with Flips, beat, or https://www.marcrobledo.com/RomPatcher.js/
3. Patched ROM: {out_size} bytes (expanded to 2 MiB), CRC32 {out_crc}, SHA-1 {out_sha1}

Notes
-----
- Tested in MesenCE 2.2.1. The ROM grows to 2 MiB; any emulator or flash cart that runs 2 MiB LoROM games works.
- Start from a cold boot. Savestates made with the Japanese ROM or an older patch can show garbled text until the
  next scene loads.
- Known issues: none. Report bugs at
  https://github.com/minhnhattonthat/gegege-no-kitarou-fukkatsu-tenma-daiou-en/issues (a savestate helps).
